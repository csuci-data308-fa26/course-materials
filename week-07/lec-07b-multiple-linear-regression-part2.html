1. Conditions

Multiple linear regression has 5 conditions:

  1. Linearity (appropriate functional form)
  2. Independence of observations
  3. Constant variance of errors
  4. Normality of errors
  5. No perfect collinearity

Perfect collinearity

Perfect collinearity = An \(X_j\) is a perfect linear combination of another

  • e.g., Using SAT Math, SAT Reading, & SAT total (total = math + reading) as 3 \(X\)’s

Cannot fit model mathematically so statistical software will drop at least one \(X\)

High Collinearity

High collinearity = highly correlated \(X\)’s

  • e.g., Suppose we wanted to include SAT Math & SAT Reading as 2 \(X\)’s

Results in:

  • larger standard errors of \(\hat{\beta}\)’s for highly correlated \(X\)’s
  • difficulty separating the association between \(Y\) and \(X_j\) from \(Y\) and \(X_k\)
  • mathematical instability resulting in high sensitivity of results to sample

High Collinearity

Remedy:

  • Determine whether both variables are scientifically necessary
  • Do not remove an important confounding variable solely because it is highly correlated with another predictor
    • Note: VIF is discussed in the ISL textbook, but we should not remove a variable only because it has a high VIF

Linear regression as a tool

When we perform multiple linear regression, we usually are interested in answering a few important questions.

  1. Is at least one of the predictors \(X_1, X_2,...,X_p\) useful in predicting the response?
  2. Do all the predictors help to explain \(Y\) , or is only a subset of the predictors useful?
  3. How well does the model fit the data?
  4. Given a set of predictor values, what response value should we predict, and how accurate is our prediction?

Q1: Is There a Linear Relationship Between the Response and Predictors?

Q1 with simple linear regression

\[Y_i = \beta_0 + \beta_1 X_i + \epsilon_i\]

Hypothesis test for \(\beta_1\)!

  • \(H_0: \beta_1 = 0\) & \(H_A: \beta_1 \neq 0\)
  • Results for this test are shown when you use summary() or tidy() on your model
  • Make your statistical decision and conclusion in context. Report confidence interval!

Q1 with multiple linear regression

\[Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + ... + \beta_p X_{p,i} + \epsilon_i\]

F-test: Hypothesis test for all \(\beta_j\)’s

  • \(H_0:\) All \(\beta_j\)’s equal 0 & \(H_A\): At least one \(\beta_j\) is non-zero
  • Results for an F-test are shown when you use summary() or glance() on your model
  • Make your statistical decision and conclusion in context. Report confidence interval!

Partial F-test for nested models

From the plots it was pretty clear lunch is linearly related to score. What if we only wanted to do a test to see if student-teacher ratio and or student-computer ratio is linearly related to score?

We can do a partial F-test for nested models!

  • \(H_0: \beta_1 = \beta_2 = 0\)
  • \(H_A:\) At least one of \(\beta_1\) or \(\beta_2\) are nonzero.

F-test with subset of coefficients

score_model1 <- lm(
  ave_score ~ student_teacher_ratio + student_computer_ratio + lunch,
  data = ca_schools

score_model2 <- lm(

Inflated Type I Error rate

Consider fitting a multiple linear regression model where all of the slopes are actually zero. In other words, none of the predictors are truly associated with the response.

  • Imagine we collect many independent samples from this population and fit the same model to each sample.
  • For each predictor, we perform an individual test using \(\alpha=0.05\).
  • For each test, there is a 5% probability of Type I error.

Inflated Type I Error rate

  • cont…
  • For each test, there is a 5% probability of Type I error.
  • Even though all \(H_0\)’s are true, approximately 5% of the tests for each predictor will produce a p-value below 0.05 by chance.
    • This means that even when none of the predictors are associated with the response, we may incorrectly conclude that some are!
    • As we test more predictors, the probability of at least one false positive increases.

Q2: Do all the predictors help to explain \(Y\), or is only a subset of the predictors useful?

Statistical Inference

If you are doing statistical inference you need to be conscious not to increase your type I error rate needlessly.

  • You should not fit a bunch of models, see what “fits best”, then do a hypothesis test (“p-hacking”)
  • Therefore you should consider ahead of time what predictors should be included based on context knowledge (lec 8a)

Model selection for prediction

Selecting a model for prediction requires evaluating how well candidate models perform on new observations.

Q3 How well does the model fit the data?

Residual Standard Error (RSE)

\[RSE = \hat{\sigma} = \sqrt{\frac{RSS}{n - 2}} = \sqrt{\frac{1}{n - 2} \sum_{i = 1}^{n} (y_i - \hat{y}_i)^2}\]

  • Measured in units of \(y\)

\(n - 2\) is required to for key statistical properties, but it is often replaced by just \(n\)

  • Using \(n\) instead of \(n - 2\) is called Root Mean Squared Error (RMSE)
  • Used to assess predictive error

Understanding RSE

What would you say is a “good” RSE/RMSE value? What would be a “bad” one?

  • You can evaluate it relative to RSE/RMSE of another model (a model with different \(X\) for the same \(Y\))
  • RMSE is “roughly” the average error, so you can think in context if the average error is acceptable or unacceptable

\(R^2\) statistic

\[R^2 = (TSS - RSS) / (TSS)\]

\(R^2\) measures percent of variability in \(Y\) explained by model

  • \(TSS = \sum_{i = 1}^{n} (y_i - \bar{y})^2\) measures amount of variability in \(Y\)
  • \(RSS\) measures amount of variability in \(Y\) unexplained by model
  • \(TSS - RSS\) measures amount of variability explained by the model

\(R^2\) statistic

What \(R^2\) be for perfectly linear data?

What would \(R^2\) be for completely unlinear data?

In practice it is context specific for what constitutes a “reasonably good” \(R^2\)

  • consider physics versus marketing

Cautions with \(R^2\)statistic

Low \(R^2\) does not mean no/(or weak) relationship, simply not a linear relationship

\(R^2\) = 0.11

Cautions with \(R^2\)statistic

High \(R^2\) does not mean a regression line fits the data well. Another function may describe it better

\(R^2\) = 0.74

Cautions with \(R^2\)

\(R^2\) will always increase as \(p\) increases

People developed Adjusted \(R^2\), which penalizes for number of predictors BUT

  • it no longer has the nice interpretation of \(R^2\)
  • still prefers larger models

Q4 Given a set of predictor values, what response value should we predict, and how accurate is our prediction?

Same as with simple linear regression!

  • We can compute a prediction by plugging in values for all of our \(X_j\)’s into our fitted model
  • We can compute a prediction interval

What do we predict the average test score will be for a school with a student-teacher ratio of 22, student-computer ratio of 10, and 50% qualifying for reduced-price lunch?

my_new_data <- data.frame(
  student_teacher_ratio = 22,
  student_computer_ratio = 10,
  lunch = 50
)

predict(score_model1, newdata = my_new_data, interval = "prediction")
       fit      lwr      upr
1 648.2898 630.2328 666.3468

We predict their average test score to be 648.29, between 630.23 and 666.35 with 95% confidence.
